# SafeAlert brand assets

Source files used to generate iOS, Android, and PWA icons/splash screens.

| File | Use |
|------|-----|
| `icon.png` | 1024×1024 app icon source |
| `splash.png` | 2732×2732 splash screen source |

## Asset usage

After editing `icon.png` or `splash.png`, use them as source files for:

- `flutter_app` launcher/splash assets (Flutter native apps)
- `public/icons/` web/PWA assets

Keep this folder as the canonical design source for both mobile and web assets.
