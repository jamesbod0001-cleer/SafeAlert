# SafeAlert NG — iOS & Android (Flutter)

SafeAlert mobile is now built as a native Flutter app in `flutter_app/`.
The web app at `/app/` remains unchanged for browsers.

---

## Architecture

```
flutter_app/
  lib/        Feature-based Flutter client (Home/Map/Insights/Routes/Circle/Report/Trust)
  android/    Native Android project (generated by Flutter)
  ios/        Native iOS project (generated by Flutter)

Backend API:
  https://<your-host>/v1
```

---

## Prerequisites

| Platform | Requirements |
|----------|--------------|
| Both | Flutter SDK 3.8+, Dart, production API URL |
| Android | Android Studio + Android SDK |
| iOS | macOS + Xcode 15+ + Apple Developer account |
| Push | Firebase project (Android + iOS apps configured) |

---

## Run in development

From repo root:

```bash
npm run flutter:run
```

Or directly:

```bash
cd flutter_app
flutter pub get
flutter run --dart-define=SAFEALERT_API=https://api.yourdomain.com/v1
```

---

## Build release artifacts

From repo root:

```bash
npm run flutter:build:android
npm run flutter:build:ios
```

Or directly:

```bash
cd flutter_app
flutter build apk --release --dart-define=SAFEALERT_API=https://api.yourdomain.com/v1
flutter build ios --release --dart-define=SAFEALERT_API=https://api.yourdomain.com/v1
```

---

## Firebase push setup (Flutter)

1. Add Android app in Firebase Console (`com.safealert.ng`) and download `google-services.json`.
2. Add iOS app in Firebase Console (`com.safealert.ng`) and download `GoogleService-Info.plist`.
3. Place files:
   - `flutter_app/android/app/google-services.json`
   - `flutter_app/ios/Runner/GoogleService-Info.plist`
4. Ensure iOS Push Notifications capability and APNs key are configured in Apple Developer + Firebase.

Note: push scaffolding exists in `flutter_app/lib/core/notifications/push_service.dart`.

---

## API and CORS

Mobile app talks directly to `/v1` over HTTPS via:

`--dart-define=SAFEALERT_API=https://.../v1`

Keep `CORS_ORIGINS` configured for browser domains; native app networking is not browser-CORS constrained.
